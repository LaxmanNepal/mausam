# 🌦️ मौसम — नेपालको स्मार्ट मौसम

नेपाली भाषालाई प्राथमिकता दिएको responsive weather dashboard। यसको dashboard संरचना `iamlaxman/nepal-sky` को `dashboard.html` बाट प्रेरित/पुनर्निर्मित गरिएको हो, तर यो repository मा UI र feature set नयाँ रूपमा व्यवस्थित गरिएको छ।

## मुख्य विशेषता

- 🇳🇵 नेपाली-first interface
- 🔎 शहर, जिल्ला तथा स्थानीय स्थान खोजी
- 📍 हालको स्थानबाट मौसम
- 🌡️ अहिलेको तापक्रम, महसुस हुने तापक्रम, अधिकतम/न्यूनतम
- ⏱️ २४ घण्टाको मौसम घडी
- ☔ आगामी १८ घण्टामा वर्षा कहिले सम्भावित भन्ने दृश्य
- 🌬️ वायु गुणस्तर, PM2.5, PM10 र AQI
- ☀️ UV सूचक
- 🗓️ ७ दिने पूर्वानुमान
- 🧭 हावाको दिशा, गति, दबाब, दृश्यता, बादल र ओसांक
- 🎯 व्यक्तिगत 'मौसम स्कोर'
- ☔ छाता चाहिन्छ कि पर्दैन भन्ने संकेत
- 🚗 यात्रा अवस्थाको सरल संकेत
- 👕 आजको कपडा सुझाव
- 🌱 किसानका लागि सरल सुझाव
- 🏃 स्वास्थ्य/बाहिरी गतिविधि सुझाव
- 🌓 डार्क मोड
- ↗️ मौसम विवरण साझा गर्ने सुविधा
- 💾 पछिल्लो स्थान सम्झने सुविधा
- 📱 PWA / offline shell caching
- ⚡ कुनै backend आवश्यक छैन

## डाटा

मौसम तथा वायु गुणस्तरका लागि Open-Meteo API र स्थान खोजीका लागि OpenStreetMap Nominatim प्रयोग गरिएको छ। API उपलब्धता/सीमाका कारण production deployment अघि provider terms र usage limits जाँच गर्नुहोस्।

## चलाउने

`index.html` लाई static hosting मा राखे पुग्छ। GitHub Pages, Cloudflare Pages, Vercel वा अन्य static host मा deploy गर्न सकिन्छ।
